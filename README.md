# $${\color{#ff00ff}Web-lab-project}$$

## Лабораторная работа №6
📌 ${\color{#FF69B4}Тема: \ To\text{-}Do \ List \ на \ Vue \ 3 \ и \ Vite}$

Версия приложения **To-Do List** из лабораторной №4 перенесена с vanilla JavaScript на Vue 3. Интерфейс разделён на компоненты, состояние хранится реактивно, а для разработки и production-сборки используется Vite.

## 🛠 Стек

- **Vue 3** — Composition API и однофайловые компоненты
- **Vite** — сервер разработки и production-сборка
- **JavaScript** — логика приложения
- **Sass (SCSS)** — модульные стили из лабораторной №4
- **HTML5** — семантическая и доступная разметка
- **localStorage** — сохранение задач и выбранной темы
- **GitHub Actions / Pages** — подготовленный способ публикации

## ✅ Возможности

- добавление новых задач через модальное окно;
- редактирование и удаление задач;
- отметка задач выполненными;
- автоматическое перемещение выполненных задач вниз списка;
- поиск задач по названию во время ввода;
- сохранение задач и темы после перезагрузки;
- безопасный запуск при повреждённых данных в `localStorage`;
- светлая и тёмная темы;
- адаптивный интерфейс и управление с клавиатуры;
- сообщения об изменениях через `aria-live`.

## 🧩 Компоненты Vue

- `App.vue` — общее состояние, производные данные и обработка действий;
- `SearchBar.vue` — поле поиска с поддержкой `v-model`;
- `TodoList.vue` — список задач и пустое состояние;
- `TodoItem.vue` — одна задача, чекбокс и кнопки действий;
- `AddTodoModal.vue` — создание и редактирование задачи;
- `ThemeToggle.vue` — переключатель светлой и тёмной темы.

Данные передаются дочерним компонентам через `props`, а действия возвращаются родителю через `emit`.

## ⚙️ Реактивность

- `ref` хранит задачи, поисковый запрос, состояние модального окна и тему.
- `computed` формирует отфильтрованный список и помещает выполненные задачи вниз, а также вычисляет сообщение пустого состояния.
- `watch` используется как осмысленный побочный эффект: изменения задач автоматически записываются в `localStorage`, а изменение темы обновляет атрибут документа и сохраняет выбор пользователя.
- `v-if` создаёт модальное окно только тогда, когда оно действительно открыто, и переключает список с сообщением пустого состояния.

## ♿ Доступность

- у полей формы и поиска есть связанные подписи;
- кнопки редактирования и удаления имеют доступные имена с названием задачи;
- интерактивные элементы доступны с клавиатуры и имеют заметный `focus-visible`;
- модальное окно реализовано через нативный `<dialog>`;
- при открытии модального окна фокус переходит в поле, после закрытия возвращается на исходную кнопку;
- после удаления задачи фокус переносится на соседнюю задачу или кнопку добавления;
- результаты действий озвучиваются через область `aria-live`;
- учитывается настройка `prefers-reduced-motion`.

## 🚀 Запуск

Требуется актуальная LTS-версия Node.js.

```bash
# установить зависимости из lock-файла
npm ci

# запустить сервер разработки
npm run dev

# создать production-сборку в dist/
npm run build

# локально открыть production-сборку
npm run preview
```

Папки `node_modules/` и `dist/` не коммитятся.

## 🌐 Публикация

В `vite.config.js` указан базовый путь `/Web_lab_project/`. Workflow `.github/workflows/ci.yaml` собирает ветку `lab6` и публикует содержимое `dist/` через GitHub Pages.

После первого push необходимо открыть **Settings → Pages → Build and deployment** и выбрать **Source: GitHub Actions**.
