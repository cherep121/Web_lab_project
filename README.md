# Поле Багов — интерактивная мем-викторина

**Автор:** Антон Чистюхин<br>
**Ветка:** `cringelab1`

«Поле Багов» — адаптивная одиночная браузерная мем-игра. Игрок выбирает тему
и уровень сложности или создаёт собственную загадку, вращает колесо, называет
буквы и может открывать составной ответ по одному слову.

## Возможности

- 24 готовые загадки по темам C++, Web, Git и «Айтишный быт»;
- генерация случайной загадки на лёгком, среднем или сложном уровне;
- редактор своего слова или фразы и подсказки;
- колесо с очками, удвоением, призом и сектором «Банкрот»;
- табло с отдельной плиткой для каждой буквы;
- ввод с клавиатуры и экранная русская клавиатура;
- подсказка показывается в начале раунда, затем скрывается под кнопкой;
- возможность назвать весь ответ или открыть только одно слово из фразы;
- очки, ошибки, раунды и простые звуковые эффекты;
- сниженная до 3% вероятность сектора «Банкрот»;
- финальные окна победы и поражения;
- доступная клавиатурная навигация и адаптивная вёрстка.

## Запуск

Сборка и установка зависимостей не нужны. Можно открыть `index.html` напрямую
или запустить локальный сервер:

```bash
python -m http.server 4173
```

После запуска откройте <http://localhost:4173/>.

## Управление

1. Выберите тему, сложность и сгенерируйте загадку либо заполните свою.
2. Запомните подсказку — через пять секунд она скроется, но её можно открыть снова.
3. Вращайте барабан перед каждой буквой.
4. Введите букву или нажмите её на экранной клавиатуре.
5. Если уверены, введите всю фразу или одно ещё не открытое слово без вращения.
6. После шести ошибок раунд считается проигранным.

## Проверка

- `node --check script.js` — синтаксис JavaScript корректен;
- автоматический браузерный сценарий проверяет одиночный режим, уровни сложности,
  составные ответы, редактор, колесо, подсказку и мобильную версию.

Публикация в GitHub выполняется только после проверки и отдельного подтверждения.
