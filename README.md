# $${\color{#ff00ff}Web\text{-}lab\text{-}project}$$

## Лабораторная работа №7
📌 $${\color{#FF69B4}Тема:\ State\ менеджмент\ и\ роутинг}$$

**TaskSpace** — учебное To-Do приложение с локальной регистрацией и входом.
Пользователь может вести личный список задач, искать и редактировать записи,
отмечать выполнение и переключать светлую и тёмную темы. Данные сохраняются в
`localStorage`, а страницы приложения связаны через Vue Router.

> Авторизация учебная и работает только в браузере, без сервера. Для проверки
> используйте вымышленные email и пароли, которые больше нигде не применяются.

## 🛠 Стек

- **Vue 3** — Composition API и однофайловые компоненты
- **Vite** — сервер разработки и production-сборка
- **Pinia** — управление пользователями и задачами
- **pinia-plugin-persistedstate** — сохранение состояния
- **Vue Router** — страницы и защита маршрутов
- **JavaScript** — логика приложения
- **Sass (SCSS)** — модульные стили и две темы
- **localStorage** — хранение пользовательских данных в браузере

## ✨ Возможности

- регистрация с проверкой email, пароля и уникальности пользователя;
- вход, выход и защита страницы задач от гостей;
- отдельный список задач для каждого аккаунта;
- добавление, редактирование, удаление, поиск и отметка выполнения;
- восстановление пользователя, задач и темы после обновления страницы;
- страницы входа, регистрации, задач и информации о приложении;
- светлая и тёмная темы;
- адаптивный интерфейс и управление с клавиатуры.

## ▶️ Установка и запуск

```bash
npm ci
npm run dev
```

Production-сборка и локальная проверка результата:

```bash
npm run build
npm run preview
```

Собранные файлы появляются в `dist/`. Папки `dist/` и `node_modules/`
исключены из Git.

## ✅ Проверка сценариев

1. Создайте аккаунт на странице регистрации.
2. Проверьте ошибки для неверного email, русских букв в email или пароле,
   разных паролей и повторной регистрации.
3. Войдите и добавьте несколько задач.
4. Проверьте поиск, редактирование, выполнение и удаление задач.
5. Создайте второго пользователя и убедитесь, что его список независим.
6. После выхода откройте `#/todo` — приложение перенаправит на страницу входа.
7. Обновите страницу и проверьте восстановление аккаунта, задач и темы.
