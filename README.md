# $${\color{#ff00ff}Web\text{-}lab\text{-}project}$$

## Лабораторная работа №10

📌 $${\color{#FF69B4}Тема:\ Архитектура\ и\ расширение\ To\text{-}Do}$$

**TaskSpace** — учебное To-Do приложение на Vue 3 и TypeScript. В этой версии
задачи получили даты начала и окончания, четыре уровня приоритета, метки,
сортировку и пять представлений списка. Данные каждого пользователя сохраняются
отдельно в `localStorage`.

**Автор:** Чистюхин Антон

**Группа:** необходимо указать

> Авторизация учебная и работает только в браузере. Для проверки используйте
> вымышленные email и пароль.

## 🛠 Стек

- **Vue 3**, **Pinia** и **Vue Router**;
- **TypeScript** со строгой проверкой типов;
- **Vite** для разработки и production-сборки;
- **ESLint** и **Prettier** для проверки качества кода;
- **Sass (SCSS)** для адаптивного интерфейса и двух тем;
- **localStorage** для пользователей и задач.

Проверено на **Node.js v24.13.0** и **npm 11.6.2**.

## ▶️ Установка и запуск

```bash
npm ci
npm run dev
```

## ✅ Проверки и сборка

```bash
npm run type-check
npm run lint
npm run format:check
npm run check
npm run build
npm run preview
```

- `check` запускает проверку типов, ESLint и проверку форматирования;
- `build` сначала выполняет `check`, затем создаёт сборку Vite;
- `format` и `lint:fix` явно исправляют форматирование и доступные ошибки;
- `preview` открывает готовую сборку локально.

## ✨ Возможности

- добавление, редактирование, удаление и выполнение задач;
- опциональные даты начала и дедлайна;
- приоритеты «Низкий», «Обычный», «Высокий» и «Срочный»;
- несколько меток у задачи;
- вкладки «Поиск», «Все», «На сегодня», «Грядущие» и «Выполненные»;
- совместный поиск по названию и метке;
- отдельный показ выполненных задач на сегодня и текущую неделю;
- личные списки пользователей, защита маршрута и сохранение темы.

## 🧱 Архитектура

Подсистема задач разделена на четыре небольшие части:

- `domain/` — модель задачи, валидация, сортировка и правила календарных дат;
- `application/` — сценарии CRUD и контракт `TodoRepository`;
- `infrastructure/` — реализации хранилища в `localStorage` и памяти;
- `stores/` и компоненты — реактивное состояние и интерфейс Vue.

Зависимости направлены от интерфейса к сценариям и домену. Сценарии работают
только с контрактом репозитория и не знают о Vue или `localStorage`. Конкретный
`LocalStorageTodoRepository` создаётся в `src/setup/todo.ts`. Чтобы использовать
память, достаточно подключить там `MemoryTodoRepository`, не меняя сценарии и
компоненты.

## 📅 Даты и сортировка

Дата из формы преобразуется в строку ISO и при отображении возвращается в
локальное время пользователя. Вкладки «На сегодня» и «Грядущие» используют
только дедлайн. Неделя считается с понедельника по воскресенье.

Сначала показываются невыполненные задачи, затем выполненные. Внутри каждой
группы задачи сортируются по убыванию приоритета, ближайшему дедлайну и более
ранней дате начала. Задачи без дедлайна или начала располагаются после задач с
соответствующей датой.

## ♻️ Прежние данные

Репозиторий читает прежний ключ `taskspace.tasks` из лабы №9. Для старых задач
автоматически используются приоритет `0`, пустой список меток и отсутствие дат.
Задачи проверяются, разделяются по пользователям и дедублируются по `id`.
Повреждённые записи пропускаются и не ломают запуск. Pinia больше не сохраняет
задачи повторно — за них отвечает только репозиторий.

## 🧪 Сценарий проверки

1. Создайте учебный аккаунт и добавьте задачу только с названием.
2. Добавьте задачи с разными приоритетами, датами и метками.
3. Проверьте порядок задач и все пять вкладок.
4. Во вкладке «Поиск» совместите текстовый запрос и фильтр метки.
5. Проверьте чекбокс показа выполненных во вкладках дат.
6. Отредактируйте, выполните и удалите несколько задач.
7. Создайте второго пользователя и убедитесь, что списки не смешиваются.
8. Перезагрузите страницу и проверьте восстановление данных и темы.
9. Выполните `npm run build` — все проверки должны завершиться успешно.
