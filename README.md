# $${\color{#ff00ff}Web\text{-}lab\text{-}project}$$

## Лабораторная работа №9

📌 $${\color{#FF69B4}Тема:\ Vue\ 3\ и\ TypeScript}$$

**TaskSpace** — учебное To-Do приложение на Vue 3 и TypeScript. Пользователь
может зарегистрироваться, войти в свой профиль и вести отдельный список задач:
добавлять, искать, редактировать, удалять и отмечать выполненные записи. Данные
пользователей, задач и выбранная тема сохраняются в `localStorage`.

**Автор:** Чистюхин Антон

**Группа:** необходимо указать

> Авторизация учебная и работает только в браузере. Для проверки используйте
> вымышленные email и пароль.

## 🛠 Стек

- **Vue 3** — Composition API и однофайловые компоненты;
- **TypeScript** — строгая типизация приложения;
- **Vite** — сервер разработки и production-сборка;
- **Pinia** и **pinia-plugin-persistedstate** — состояние и сохранение данных;
- **Vue Router** — страницы и защита маршрутов;
- **ESLint** и **Prettier** — проверка и форматирование кода;
- **Sass (SCSS)** — адаптивные стили и две темы.

Проверено на **Node.js v24.13.0** и **npm 11.6.2**.

## ▶️ Установка и запуск

```bash
npm ci
npm run dev
```

После запуска Vite покажет локальный адрес приложения в терминале.

## ✅ Проверки и сборка

```bash
npm run type-check
npm run lint
npm run format:check
npm run check
npm run build
npm run preview
```

- `type-check` проверяет Vue-компоненты и TypeScript без создания файлов;
- `lint` проверяет правила JavaScript, TypeScript и Vue;
- `format:check` проверяет форматирование;
- `check` последовательно запускает все три проверки и ничего не исправляет;
- `build` сначала запускает `check`, затем создаёт production-сборку Vite;
- `preview` локально открывает готовую сборку.

Проверка типов находит несоответствия типов в исходном коде и шаблонах. Vite
преобразует TypeScript в JavaScript и собирает приложение, но не заменяет
полноценную проверку через `vue-tsc` и `tsc`.

Автоматическое форматирование и исправление доступных ошибок:

```bash
npm run format
npm run lint:fix
```

## ✨ Возможности

- регистрация и вход с проверкой введённых данных;
- защита страницы задач от гостей;
- отдельные задачи для каждого учебного аккаунта;
- добавление, поиск, редактирование, удаление и выполнение задач;
- восстановление данных лабы №7 без изменения ключей `localStorage`;
- страницы входа, регистрации, задач и информации о приложении;
- светлая и тёмная темы;
- адаптивный и доступный интерфейс.

## 🧪 Сценарий проверки

1. Выполните `npm ci`, затем `npm run dev`.
2. Создайте учебный аккаунт с вымышленными email и паролем.
3. Добавьте задачи и проверьте поиск, редактирование, выполнение и удаление.
4. Создайте второго пользователя и убедитесь, что списки не смешиваются.
5. Выйдите и откройте `#/todo`: приложение перенаправит на страницу входа.
6. Войдите повторно и убедитесь, что задачи сохранились.
7. Обновите страницу и проверьте восстановление пользователя, задач и темы.
8. Выполните `npm run build` — все проверки и сборка должны завершиться успешно.
