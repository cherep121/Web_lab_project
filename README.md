# Лабораторная работа №5 — Введение в Vue 3

Учебное одностраничное приложение с семью мини-заданиями на основные возможности Vue 3. Все компоненты находятся в одном файле `index.html`, Vue подключается через CDN, поэтому сборка проекта не требуется.

- ФИО: Антон Чистюхин
- Группа: не указана

## Реализованные задания

1. Приветствие с двусторонней привязкой через `v-model` и Options API.
2. Реактивный счётчик на `ref`.
3. Показ и скрытие описания с помощью `v-if` / `v-else`.
4. Вывод списка через `v-for` с уникальными ключами.
5. Мини-форма добавления пользователей и очистка полей после отправки.
6. Вычисление квадрата и куба числа через `computed`.
7. Часы с обновлением раз в секунду, `watch` и хуками жизненного цикла.

## Запуск

Проект не требует установки зависимостей или сборки.

1. Склонируйте репозиторий и перейдите в ветку `lab-5`.
2. Откройте `index.html` в браузере.

Для запуска через локальный HTTP-сервер можно выполнить:

```bash
python -m http.server 8000
```

После этого откройте <http://localhost:8000>.

Для загрузки Vue 3 при первом открытии страницы требуется подключение к интернету.
