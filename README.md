# TaskSpace — лабораторная работа №7

**Автор:** Антон Чистюхин<br>
**Группа:** не указана

TaskSpace — учебное To‑Do приложение на Vue 3. Пользователь может создать локальный
аккаунт, войти, вести личный список задач и переключать светлую и тёмную темы.
Состояние пользователей и задач организовано через Pinia и сохраняется в
`localStorage`, а переходы между страницами выполняет Vue Router.

> Авторизация учебная и работает только в браузере, без сервера. Для проверки
> используйте вымышленные email и пароли, которые больше нигде не применяются.

## Возможности

- регистрация с проверкой латинского email, пароля без русских букв, совпадения паролей и уникальности пользователя;
- вход, выход и защита страницы задач от гостей;
- отдельные задачи для каждого зарегистрированного пользователя;
- добавление, редактирование, удаление, поиск и отметка выполнения задач;
- сохранение аккаунтов, текущего входа, задач и темы после перезагрузки;
- страницы входа, регистрации, задач и «О приложении»;
- адаптивный интерфейс, управление с клавиатуры и видимый фокус;
- светлая и тёмная темы.

## Стек

- Vue 3 и Vite;
- Pinia и `pinia-plugin-persistedstate`;
- Vue Router с hash-history для прямого открытия страниц на GitHub Pages;
- JavaScript и SCSS.

## Установка и запуск

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Собранные файлы появляются в `dist/`. Папки `dist/` и `node_modules/` исключены
из Git.

## Как проверить сценарии

1. Откройте «Регистрация» и создайте аккаунт с вымышленными данными.
2. Проверьте ошибки: неверный email, русские буквы в email или пароле, разные пароли и повторную регистрацию того же email.
3. Войдите и добавьте несколько задач. Отредактируйте, выполните, найдите и удалите задачу.
4. Выйдите, зарегистрируйте второго пользователя и убедитесь, что список пуст.
5. Вернитесь в первый аккаунт — его задачи должны сохраниться.
6. После выхода откройте `#/todo`: приложение должно перенаправить на страницу входа.
7. Обновите страницу и проверьте восстановление текущего входа, задач и темы.

## Структура

```text
src/
├─ components/       # компоненты списка, поиска, модалки и темы
├─ pages/            # LoginPage, RegisterPage, TodoPage, AboutPage
├─ router/index.js   # маршруты и проверка доступа
├─ stores/           # useUserStore и useTodoStore
├─ App.vue           # навигация и общий каркас
└─ main.js           # подключение Pinia и Vue Router
```
