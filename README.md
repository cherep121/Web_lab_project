# Лабораторная работа №8 — основы TypeScript

**Автор:** Антон Чистюхин<br>
**Группа:** не указана<br>
**Ветка:** `lab-8`

Консольный практикум из девяти задач на TypeScript: перегрузки функций,
кортежи и перечисления, функции-сторожи, иммутабельные коллекции, обобщения,
`reduce`, классы и рекурсивные типы. Каждый файл является отдельным модулем и
содержит реализацию вместе с примерами использования.

## Окружение

- Node.js `v24.13.0`;
- npm `11.6.2`;
- TypeScript и типы Node.js устанавливаются как `devDependencies`;
- ES-модули, `NodeNext`, строгая типизация и `noEmitOnError`.

## Установка и проверка

```bash
npm ci
npm run check
npm run build
```

`npm run check` проверяет типы без создания файлов. `npm run build` компилирует
исходники из `src/` в `dist/`. Папки `node_modules/` и `dist/` исключены из Git.

После сборки каждую задачу можно запустить отдельно:

```bash
node dist/task1.js
node dist/task2.js
# ...
node dist/task9.js
```

Для запуска всех задач в PowerShell:

```powershell
1..9 | ForEach-Object { node "dist/task$_.js" }
```

## Выполненные задачи

| № | Файл | Реализация и ожидаемый результат |
|---|---|---|
| 1 | `src/task1.ts` | Три перегрузки `formatInput`: число получает два знака после точки, строка очищается по краям, дата выводится в ISO-формате. В реализации используются `instanceof`, `switch` и проверка `never`. |
| 2 | `src/task2.ts` | Кортеж RGB, `enum ColorName`, перевод всех заданных цветов в `#rrggbb`. Некорректный канал `256` вызывает и обрабатывает `RangeError`. |
| 3 | `src/task3.ts` | Брендированный `UserId` и сторож UUID. Профиль создаётся только для корректной строки; неверная строка и число отклоняются. |
| 4 | `src/task4.ts` | Иммутабельные `addTag`, `removeTag`, `mergeTags`. Результаты создаются заново, порядок первого появления сохраняется, исходные массивы выводятся без изменений. |
| 5 | `src/task5.ts` | Обобщённые перегрузки pipeline для одного, двух и трёх шагов. Показана цепочка `number → number → string → string`, а несовместимый вызов оставлен в комментарии. |
| 6 | `src/task6.ts` | `reduce` считает суммы `paid` и `free`. Для смешанного набора ожидается `{ paid: 2000, free: 350 }`, для пустого — два нуля. |
| 7 | `src/task7.ts` | Generic-разбиение чисел и строк на блоки без мутации. Проверяются остаток, пустой массив и ошибки для `0`, отрицательного, дробного, `NaN` и бесконечного размера. |
| 8 | `src/task8.ts` | Интерфейс `Repository` и класс `MemoryRepository` с CRUD для книг. Показаны обновление, удаление, отсутствующая запись и обработка повторного `id`. |
| 9 | `src/task9.ts` | Рекурсивные `DeepReadonly` и `deepFreeze`. `Object.isFrozen()` подтверждает заморозку корня, вложенных объектов, массива и его элементов. Недопустимые изменения показаны комментариями. |

Ожидаемые исключения перехватываются через `try/catch`, поэтому каждый файл
завершает выполнение без необработанной ошибки. В исходниках не используются
`any`, `@ts-ignore` и `@ts-nocheck`.
