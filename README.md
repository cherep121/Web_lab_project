# $${\color{#ff00ff}Web\text{-}lab\text{-}project}$$

## Cringe Lab №1
📌 $${\color{#FF69B4}Тема:\ Интерактивная\ мем\text{-}игра\ «Поле\ Багов»}$$

**«Поле Багов»** — адаптивная одиночная браузерная игра. Пользователь выбирает
тему и уровень сложности или создаёт собственную загадку, вращает колесо,
называет буквы и открывает составной ответ по одному слову.

## 🛠 Стек

- **HTML5** — экраны настройки, игры и результата
- **CSS3** — адаптивное оформление игрового поля и колеса
- **JavaScript** — загадки, очки, управление и игровая логика
- **Web Audio API** — простые звуковые эффекты
- **GitHub Actions / Pages** — автоматическая публикация игры

## ✨ Возможности

- 24 готовые загадки по темам C++, Web, Git и «Айтишный быт»;
- лёгкий, средний и сложный уровни;
- редактор собственного слова или фразы и подсказки;
- колесо с очками, удвоением, призом и сектором «Банкрот»;
- сниженная до 3% вероятность выпадения «Банкрота»;
- отдельная плитка для каждой буквы;
- ввод с физической и экранной русской клавиатуры;
- автоматическое скрытие и повторный показ подсказки;
- возможность открыть одно слово или назвать всю фразу;
- очки, ошибки, раунды и финальные окна;
- адаптивная вёрстка и клавиатурная навигация.

## ▶️ Запуск

Сборка и установка зависимостей не требуются. Можно открыть `index.html`
напрямую или запустить локальный сервер:

```bash
python -m http.server 4173
```

После запуска откройте <http://localhost:4173/>.

## 🎮 Как играть

1. Выберите тему и уровень сложности либо создайте свою загадку.
2. Запомните подсказку — через пять секунд она автоматически скроется.
3. Вращайте колесо перед каждой попыткой назвать букву.
4. Вводите буквы с клавиатуры или нажимайте экранные кнопки.
5. Для составной фразы можно отгадывать каждое слово отдельно.
6. После шести ошибок раунд завершается поражением.

## ✅ Проверка

```bash
node --check script.js
```

Дополнительно проверены редактор загадки, уровни сложности, составные ответы,
колесо, подсказка, одиночный режим и мобильная версия.
