# $${\color{#ff00ff}Web\text{-}lab\text{-}project}$$

## Лабораторная работа №8
📌 $${\color{#FF69B4}Тема:\ Основы\ TypeScript\ и\ Node.js}$$

Консольный практикум из девяти задач на TypeScript: перегрузки функций,
кортежи и перечисления, функции-сторожи, иммутабельные коллекции, обобщения,
`reduce`, классы и рекурсивные типы. Каждый файл является отдельным модулем и
содержит реализацию вместе с примерами использования.


## 🛠 Стек

- **TypeScript** — строгая типизация и компиляция исходного кода
- **Node.js v24.13.0** — запуск скомпилированных заданий
- **npm** — установка зависимостей и запуск команд
- **ES Modules / NodeNext** — модульная система проекта
- **Git** — контроль версий

## 🧩 Выполненные задания

1. `task1.ts` — перегрузки `formatInput`, сужение типов и проверка через `never`;
2. `task2.ts` — RGB-кортеж, `enum ColorName`, преобразование в HEX и валидация;
3. `task3.ts` — брендированный `UserId` и функция-сторож UUID;
4. `task4.ts` — иммутабельное добавление, удаление и объединение тегов;
5. `task5.ts` — обобщённый pipeline для одной, двух и трёх функций;
6. `task6.ts` — подсчёт сумм счетов по статусам через `reduce`;
7. `task7.ts` — generic-разбиение массива на блоки с проверкой размера;
8. `task8.ts` — интерфейс и класс репозитория с CRUD-операциями;
9. `task9.ts` — рекурсивные `DeepReadonly` и `deepFreeze`.

Ожидаемые ошибки обрабатываются через `try/catch`, поэтому задания завершаются
без необработанных исключений.

## 📦 Установка и проверка

```bash
npm ci
npm run check
npm run build
```

- `npm run check` проверяет типы без создания файлов;
- `npm run build` компилирует исходники из `src/` в `dist/`;
- `node_modules/` и `dist/` исключены из Git.

## ▶️ Запуск

Собрать проект и запустить все задания с отдельными заголовками:

```bash
npm start
```

Если проект уже собран:

```bash
npm run run:all
```

Запуск одного задания:

```bash
node dist/task1.js
node dist/task2.js
# ...
node dist/task9.js
```
