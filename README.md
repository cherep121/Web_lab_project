# $${\color{#ff00ff}Web-lab-project}$$

## Лабораторная работа №5
📌 ${\color{#FF69B4}Тема: \ Введение \ в \ Vue \ 3}$

Учебное одностраничное приложение с семью практическими заданиями на основные возможности **Vue 3**. Все компоненты размещены в одном HTML-файле, Vue подключается через CDN, поэтому проект работает без сборщика.

## 🛠 Стек

- **HTML5** — структура страницы и семантическая разметка
- **CSS3** — адаптивное оформление компонентов
- **JavaScript** — логика приложения
- **Vue 3** — реактивность и компоненты
- **Options API** — первое задание
- **Composition API** — задания 2–7
- **Git** — контроль версий

## ✅ Реализованные задания

1. **Приветствие** — ввод имени через `v-model`, данные хранятся в `data()`.
2. **Реактивный счётчик** — увеличение значения на `+1`, `+2` и `+5` с использованием `ref`.
3. **Условный рендеринг** — показ и скрытие описания через `v-if` / `v-else`.
4. **Список элементов** — вывод данных через `v-for` с уникальными ключами `:key`.
5. **Мини-форма** — добавление и удаление записей, очистка полей после отправки.
6. **Вычисляемые свойства** — расчёт квадрата и куба числа через `computed`.
7. **Watch и жизненный цикл** — часы, приветствие по времени суток и отслеживание изменений через `watch`.

## 📁 Структура

```text
Web-lab-project/
├─ index.html  <-- разметка, стили и семь Vue-компонентов
├─ README.md   <-- описание лабораторной работы
└─ .gitignore  <-- исключения Git
```

**Описание:**

- `index.html` — основная страница приложения;
- стили находятся внутри тега `<style>`;
- компоненты заданий описаны через `defineComponent` внутри тега `<script>`;
- первое задание использует Options API;
- задания 2–7 используют Composition API;
- переключение между заданиями выполнено через динамический компонент `<component :is="...">`;
- Vue 3 подключается из CDN без Vite и дополнительных зависимостей.

## 🚀 Запуск

Установка зависимостей и сборка не требуются.

1. Переключитесь на ветку `lab-5`.
2. Откройте файл `index.html` в браузере.

Для запуска через локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте <http://localhost:8000>.

> Для загрузки Vue 3 через CDN требуется подключение к интернету.
